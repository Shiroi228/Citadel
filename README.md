# Citadel
docs_creater.py - скрипт для создания тестовых данных

cfg.json - файл конфигурации

=======================================

# Для тестирования
1. Создать тестовые данные (запустить docs_creater.py)
2. Переместить их и файл конфигурации (cfg.json) в директорию с бинарником (Citadel.exe)
3. Запустить (./Citadel.exe *.txt)
